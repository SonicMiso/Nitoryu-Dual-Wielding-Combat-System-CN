# Nitoryu CN

这是 [Nitoryu: Dual Wielding Combat System](https://steamcommunity.com/sharedfiles/filedetails/?id=3812165089) 的中文语言附属 Mod。

## 安装

本 Mod 按原作者 `TRANSLATING.md` 的结构制作，不修改 Nitoryu 本体：

```
Nitoryu CN/
├── Nitoryu CN.mod
└── lang/
    └── zh.ini
```

将整个 `Nitoryu CN` 文件夹作为独立 Mod 安装，并让它加载在原版 `Nitoryu` 之后。

如果使用 Workshop，订阅本 Mod 后由 Kenshi/Steam 管理 Workshop Mod 文件；不要把 `zh.ini` 放入原 Nitoryu Workshop 文件夹。
